Principles

One accent, one alarm

Yellow marks what's active, live or selected. Red is reserved for permit breaches and actions that stop production. Nothing else competes for attention.

A drawing, not a render

The plant is drawn as flat outlines with an orthographic camera, so it reads like a schematic from any angle and the data stays the focus.

Humans decide

Automation (capture vents) and the copilot act or recommend, but only an operator can shut a line down, and always through a confirmation step.

Numbers you can cite

Figures use the display face with tabular numerals. Every report value traces back to a logged record, and the copilot fetches data before it answers.

Color

Dark only, by design. Swatches are generated from the token file; an arrow shows a token that points at another one, so changing the accent updates everything that uses it.

Emission scale

Used for smoke and fence sensors: normal, elevated, over the limit.

Typography

Chakra Petch, a squared technical face, carries headings, figures and controls. Archivo handles running text. Both use tabular numerals so live figures don't jitter.

Buttons

.btn.primary for the main action, .btn for secondary, .btn.danger only for actions that stop production, and only after a confirmation step. .sim is the demo control that sits over the 3D view.

Chart

Built by buildChart(spec) in assets/js/lib.js: line or bar, up to four series coloured --color-chart-1 to 4, and an optional dashed reference line in the alarm colour for a limit or target. Line charts fit their axis to the data and leave gaps for missing values.
